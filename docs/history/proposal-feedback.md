# Proposal summary and teacher feedback

> Historical record, kept as written. Paths and environment names (for example `gpu_env`) describe the setup at the time.
> Current docs: [README](../../README.md).

Project desc :
An interactive system where several agents, each using a different classical decision theory model, face the same trolley style ethical dilemma at the same time. Each agent makes a decision and explains its reasoning, so we can compare how different frameworks reason under the same conditions.

Teachers feedback :
The overall concept is interesting, but comparing utilitarian, deontological, and other classical frameworks on a common dilemma has already been explored in computational ethics. Its novelty will depend largely on what the students discover from the comparison, rather than on simply implementing several agents with different decision rules. A useful research question would be whether these frameworks consistently produce different decisions when the same ethical situation is modified in controlled ways. The explanation generated by each agent can add value if the project evaluates the consistency and justification of those explanations, instead of only displaying the final choice.
